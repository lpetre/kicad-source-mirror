Crate: kicad-pcb

C++ sources to port: common/eda_text.cpp, include/eda_text.h, pcbnew/pcb_text.cpp, pcbnew/pcb_field.cpp
Notes: Read rust/docs/analysis/text-font.md sections 4 and 11 (EdaText geometry: TF4, TF5): the three geometry paths (DRC effective shape, TransformTextToPolySet, plotting) give different coordinates on purpose. The stroke font, layout engine and markup parser are complete in kicad-font (read its PORT_STATUS.md api notes). Outline fonts: use the stored render cache when present, otherwise the documented stroke fallback. Text variable expansion core is kicad_core::text_vars; board/footprint resolvers belong to M22/M19 (call their stubs).
