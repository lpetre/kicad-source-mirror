# Script for the DSNLEXER comparison between the C++ original (tests/oracle/oracle.cpp, mode
# "script") and the Rust port (tests/oracle_goldens.rs).  lexer_script.out is the transcript
# the C++ program prints for it.
#
# One command per line: a command word and, behind one space, its argument.  Text arguments
# are escaped: \xHH stands for the byte HH (\x0a newline, \x09 tab, \x5c backslash, \x00 NUL).
#
#   source <name>              source name for the lexers made from here on (default "src")
#   lexer <keywords> <text>    make a lexer reading <text>; <keywords> is a module of
#                              kicad_sexpr::keywords or "none"
#   lexer_no_reader <keywords> make a lexer without line reader
#   lexer_repeat <keywords> <count> <text>   make a lexer reading <text> repeated <count> times
#   specctra|knowsbar|comments|spaceinquoted <0|1>, delim <char>     the setters
#   next, nexttok, all, needleft, needright, needbar, needsymbol, needsymbolornumber, neednumber <text>
#   expecting <int>, expectingstr <text>, unexpected <int>, unexpectedstr <text>, duplicate <int>
#   state, readcomments, fromutf8, curstrastoken, tokentext <int>, tokenstring <int>,
#   issymbol <int>, parsedouble, parsedoubleexp <text>, parsedoubletok <int>,
#   parseint, parseintexp <text>, parsehex, push <text>, pop, init,
#   sub <keywords> / endsub / dropsub      a second lexer sharing the line reader
